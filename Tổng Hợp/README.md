# Tổng Hợp Các Bài Thực Hành LAB211

Thư mục này chứa bộ sưu tập các bài lab thực hành môn Lập trình Java hướng đối tượng (LAB211), bao gồm mã nguồn đầy đủ và tài liệu câu hỏi ôn tập / phỏng vấn (`CAU_HOI_CHI_DOAN_CODE.txt`, `REVIEW_MAU_VA_CAU_HOI.txt`).

## Danh sách bài thực hành trong thư mục:
- [J1.L.P0025_NormalizeText](./J1.L.P0025_NormalizeText/README.md): Chuẩn hóa văn bản từ file `input.txt` sang `output.txt`.
- [J1.S.P0008_CounterWord](./J1.S.P0008_CounterWord/README.md): Đếm tần suất từ và ký tự trong chuỗi văn bản.
- [J1.S.P0010_LinearSearch](./J1.S.P0010_LinearSearch/README.md): Thuật toán tìm kiếm tuyến tính trên mảng số nguyên ngẫu nhiên.
- [J1.S.P0052_ManagerContries_FinalUpdate](./J1.S.P0052_ManagerContries_FinalUpdate/README.md): Quản lý thông tin địa lý các quốc gia Đông Á.
- [J1.S.P0056_ManagerWorker](./J1.S.P0056_ManagerWorker/README.md): Quản lý công nhân và lịch sử tăng/giảm lương.
- [J1.S.P0061_ManagerShape_FinalFixed](./J1.S.P0061_ManagerShape_FinalFixed/README.md): Tính diện tích và chu vi hình học (Rectangle, Circle, Triangle).
- [J1.S.P0070_TPBank](./J1.S.P0070_TPBank/README.md): Đăng nhập hệ thống Ebank đa ngôn ngữ (vi/en) và xác thực Captcha.
- [J1.S.P0071_TaskManager](./J1.S.P0071_TaskManager/README.md): Quản lý tiến độ công việc (Task Management: Code, Test, Design, Review).
- [J1.S.P0074_MatrixOOP](./J1.S.P0074_MatrixOOP/README.md): Máy tính đại số ma trận theo hướng đối tượng (Cộng, Trừ, Nhân).
- **Tổng Hợp txt**: Chứa các file tóm tắt mã nguồn và tài liệu ôn tập câu hỏi code.
