Q1. "Tích vô hướng (dot product) nằm ở đoạn code nào?"
────────────────────────────────────────────────────────────────────────────────
ĐÁP ÁN:
  File: entity/Matrix.java
  Method: multiply(Matrix other)
  Dòng: 76–77 (vòng for k + phép nhân-cộng dồn)

  for (int k = 0; k < this.getCols(); k++) {
      result.data[i][j] += this.data[i][k] * other.data[k][j];
  }

GIẢI THÍCH NÓI:
  "Với mỗi ô kết quả C[i][j], em duyệt k dọc theo hàng i của A và cột j của B.
   Cộng dồn A[i][k] * B[k][j] — đó chính là tích vô hướng của hàng i và cột j."

SƠ ĐỒ NHANH:
  Hàng i của A:   A[i][0]  A[i][1]  ...  A[i][n-1]
  Cột j của B:    B[0][j]
                  B[1][j]
                  ...
                  B[n-1][j]
  C[i][j] = A[i][0]*B[0][j] + A[i][1]*B[1][j] + ... + A[i][n-1]*B[n-1][j]


────────────────────────────────────────────────────────────────────────────────
Q2. "Vì sao dùng += mà không dùng = ?"
────────────────────────────────────────────────────────────────────────────────
ĐÁP ÁN:
  Dòng 77: result.data[i][j] += this.data[i][k] * other.data[k][j];

  Vì tích vô hướng là TỔNG nhiều tích con theo k.
  - Lần k=0: cộng phần tử đầu
  - Lần k=1: cộng tiếp phần tử thứ hai
  - ...
  setSize tạo mảng int mặc định = 0 → bắt đầu từ 0 rồi += là đúng.

  Nếu viết = thì mỗi lần k sẽ GHI ĐÈ, chỉ còn tích của k cuối → SAI.


────────────────────────────────────────────────────────────────────────────────
Q3. "Ba vòng for i, j, k mỗi vòng làm gì?"
────────────────────────────────────────────────────────────────────────────────
ĐÁP ÁN — Matrix.java dòng 74–79:

  for (int i = 0; i < this.getRows(); i++) {          // i = hàng của A = hàng của C
      for (int j = 0; j < other.getCols(); j++) {     // j = cột của B = cột của C
          for (int k = 0; k < this.getCols(); k++) {  // k = chiều chung (cols A = rows B)
              result.data[i][j] += this.data[i][k] * other.data[k][j];
          }
      }
  }

BẢNG:

  Biến | Chạy từ          | Ý nghĩa
  -----|------------------|----------------------------------
  i    | 0 → rowsA-1      | Chọn hàng kết quả / hàng A
  j    | 0 → colsB-1      | Chọn cột kết quả / cột B
  k    | 0 → colsA-1      | Duyệt để tính tích vô hướng

────────────────────────────────────────────────────────────────────────────────
Q8. "Cho số cụ thể, C[0][0] tính ở những lệnh nào?"
────────────────────────────────────────────────────────────────────────────────
Ví dụ:
  A = [1 2 3]     B = [7  8]
      [4 5 6]         [9 10]
                      [11 12]

Khi i=0, j=0, vòng k chạy:
  k=0: result[0][0] += 1*7   → 7
  k=1: result[0][0] += 2*9   → 7+18=25
  k=2: result[0][0] += 3*11  → 25+33=58

→ Đúng 1 dòng code 77, lặp 3 lần với i=0, j=0.

# 8. MẪU TRẢ LỜI KHI THẦY CHỈ VÀO MÀN HÌNH: "DÒNG NÀY LÀM GÌ?"
################################################################################

Nếu thầy trỏ:

  result.data[i][j] += this.data[i][k] * other.data[k][j];

Nói mẫu (~15 giây):
  "Đây là bước tính tích vô hướng cho phần tử kết quả hàng i cột j.
   this.data[i][k] là phần tử trên hàng i của ma trận 1,
   other.data[k][j] là phần tử trên cột j của ma trận 2,
   k chạy hết chiều chung; += để cộng tất cả các tích lại."


Nếu thầy trỏ:

  if (this.getCols() != other.getRows())

Nói mẫu:
  "Đây là điều kiện được phép nhân ma trận: số cột ma trận trái
   phải bằng số hàng ma trận phải. Không bằng thì throw, không tính tiếp."


Nếu thầy trỏ:

  result.setSize(this.getRows(), other.getCols());

Nói mẫu:
  "Tạo ma trận kết quả kích thước hàng của A nhân cột của B,
   đúng lý thuyết nhân ma trận (m×n)*(n×p) = (m×p)."
